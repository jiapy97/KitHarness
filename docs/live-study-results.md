## 实验配置

- 宿主：Claude Code 2.1.312；原生 CLI 在 macOS 默认拒绝沙箱内运行。
- 用户最初授权 Sonnet 4.6、10 美元。Micu 生成接口连续三次拒绝客户端、未观察到扣量；随后用户明确选择本机已有的 DeepSeek 配置作为回退。
- 实际统一请求和返回的模型 ID：`deepseek-flash`，使用官方 Anthropic 兼容接口。不是将 Claude 别名当作真正的 Claude 模型。
- 无学习组不加载插件、不保留技能；原版固定 `f2de058`，KitHarness 固定 `b232f74`；每个求解任务使用独立会话和冻结技能库副本。
- 6 类合成工作流、24 个用例，任务和确定性 JSON 评分沿用[第十步协议](task-evaluation.md)。只做 1 次重复，不声明统计显著性。

DeepSeek 官方当前将该 API 模型名对应为 DeepSeek-V4.1-Flash-1017，见[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)。
本实验验证请求和返回的 ID 一致，不声称独立审计过提供商的模型权重。

## 完整链路确实执行了什么

| 阶段 | 实际成功 CLI 会话 | 处理方式 |
| --- | --- | --- |
| 三组小预检 | 3 | 同一 UTC 任务，先确认真实模型身份和协议 |
| 预热 | 18 | 每组看到同样 6 条经验；不提供待测题答案 |
| 反思 | 2 | 每个学习组对训练窗口批量反思一次，使用各自固定的 agent 正文和生产 bundle |
| 整理 | 2 | 每个学习组各执行一次真实整理会话 |
| 正式求解 | 18 | 每组 6 个新会话，独立技能副本，全部收集后统一评分 |
| 合计 | **43** | 另保留 3 次 Sonnet 失败，总 API 授权账本为 **46 次** |

反思和整理通过原生 MCP `stage_skill` 提交提案，由各自版本的生产 promoter 校验并落地。
原版反思创建 5 个技能；整理接受 2 个创建和 4 个归档提案，最终有 3 个存活技能。
KitHarness 反思创建 2 个技能，整理后仍为 2 个。整理者没有提出变更也属于真实执行结果。

这是**显式批量维护**实验，不是生产自动触发频率测试；各角色强制使用同一 DeepSeek 模型，未沿用 agent 前置信息中的 Haiku 默认值。
正式求解只提供 Read/Grep/Glob，维护阶段另允许 stage_skill；没有 Bash、Write、Edit、Agent 或通用网络工具。
未授权的后台 Claude 调用路径被阻断，维护调用全部由统一控制器计量。

## 求解结果与开销

| 指标 | 无学习 | 原版 | KitHarness |
| --- | ---: | ---: | ---: |
| 全任务通过 | 6/6 | 6/6 | 6/6 |
| 用例正确 | 24/24 | 24/24 | 24/24 |
| 冻结后存活技能数 | 0 | 3 | 2 |
| 每任务平均插件注入 | 0 字节 | 582 字节 | 506 字节 |
| 每任务平均墙钟耗时 | 3.40 秒 | 6.28 秒 | 4.42 秒 |
| 求解阶段技能文件 Read 次数 | 0 | 7 | 3 |
| 求解阶段 Token 峰值单价估算 | $0.009622 | $0.013549 | $0.011733 |

KitHarness 本轮平均插件注入较原版少 **13.1%**，平均墙钟耗时较低，但只能描述为本轮观察：

- 注入计量读取真实 hook stdout 中的 additionalContext，包含上次执行摘要。不是全会话 Token，也不包括随后读取的技能正文。
- 两组生成的技能库不同，数量和描述都不同；因此不能把差异全部归因于 BM25 或预算算法。
- Read 是观察/消费证据，不等于 Skill 工具调用计数；本轮没有测试原生 Skill 自动选择的效果。
- 单次重复受模型随机性、缓存及网络影响，不能推广为普遍延迟保证。
- 无学习组同样满分且更便宜，说明这组题还不足以证明学习成本能回本。不能据此写“正确率提高”或“整体 Token 节省 13.1%”。

## 费用口径与预算

批准的总预算为 **10 美元**，实验完成后账本已封存，剩余名额不能用于新任务。

| 口径 | 本轮观察 |
| --- | ---: |
| DeepSeek 返回 Token × 官方峰值单价的保守估算，含所有阶段 | **$0.101829** |
| 原生 CLI 自己显示的估算 | $2.107143 |
| DeepSeek 共享账户余额观测差额 | **0.15 CNY** |
| 已成功计量的调用 | 43 次 DeepSeek，加 3 次零费用回执的 Sonnet 失败 |

三者不是同一口径。CLI 对自定义后端的估算不能当作 DeepSeek 账单。
保守估算使用公开峰值单价：每百万输入未命中 $0.30、缓存命中 $0.006、输出 $1.20，未假定低谷折扣。
[官方价格和扣费说明](https://api-docs.deepseek.com/quick_start/pricing/)与[余额接口](https://api-docs.deepseek.com/api/get-user-balance/)提供计量依据。
余额差可能包含共享账户的其他并发使用和接口取整，不能冒充逐请求发票。

控制器启动前持锁预留额度，失败不退还名额或预留；逐次核对 Token 估算和余额，遇到未知费用、模型漂移或异常立即停止。
控制器预留上限、CLI 单会话估算参数与事后余额核对，不等于提供商服务端信用硬限额，也不是独立 HTTP 请求计数。
本轮已保留[三个 Sonnet 失败回执](../evals/live/real-study/failed-sonnet.json)，没有伪造成功或重置预算。

## 隔离、冻结和可复核证据

- 实际 CLI 初始化流验证指定插件和 MCP；所有成功会话返回相同模型 ID，使用工具落在角色允许集合内。
- 训练完成后冻结每组技能库；18 份求解副本起始一致，结束后技能正文和附件摘要未变化。状态计数允许在副本内变化。
- 在实际评测策略上运行固定合成探针和未隔离正向对照，验证评分读取、越界写入和回环连接被拒绝，见[隔离证据](../evals/live/real-study/isolation.json)。
- 个人技能库、Keychain、原项目 `.env` 与 CC Switch 数据库不向模型开放。认证只在控制器内存和私有进程管道/环境中传递。
- [证据包](../evals/live/real-study/evidence.tar.gz)含 197 个文件：脱敏并移除 thinking 块的调用流、答案、学习技能/归档、固定清单和控制器源码快照；不含凭据来源或原生 CLI 配置。
- [证据目录及摘要](../evals/live/real-study/evidence-manifest.json)可检测误改；摘要和事后源码快照不是防恶意操作者的签名或远程执行证明。

离线校验与重新评分，不读密钥、不解压执行候选代码、不调用模型：

```sh
PYTHONPATH=src python3.12 tools/check_live_evidence.py evals/live/real-study
```

本机已重验 197 份文件摘要和 18 份答案，三组仍为 6/6、24/24。
生成式输出本身有随机性；这条命令复现保存结果的评分，不声称再次发模型请求会逐字得到同样答案。

## 反思与可用结论

已得到的工程证据是：真实宿主、反思者、整理者、MCP 提案、确定性落地、冻结库评测及全阶段预算账本能够接通。
生命周期代码在 SessionStart 运行，但本轮没有强制构造生命周期退役；整理归档 4 个技能不能写成生命周期退役了 4 个技能。

若要进一步证明学习或任务感知召回提高能力，需要更难、更多且独立的任务、多次重复，以及固定相同技能库的检索消融。
这些属于后续实验，不会为了得到更好看的数字在本轮追加调用或改写评分。
第十一步按这一轮受控实验的范围验收完成；第十二步品牌、演示与项目说明尚未开始。
